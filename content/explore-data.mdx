## Overview

Explore Data provides a guided way to search, refine, and answer wealth-related questions with strong visual context and approachable controls.

## Technical Breakdown

The pipeline uses **Python**, **LangChain**, and **LLM** tooling for query support and enrichment, while the frontend is built with **Next.js** and **React** using **D3**, **Leaflet**, and **turf.js** for spatial and chart-based analysis.
