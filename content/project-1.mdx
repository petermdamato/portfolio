## Overview

This project explores wealth distribution across census tracts, providing an interactive map that visualizes economic disparities. The goal was to build a performant, accessible tool for researchers and policymakers.

## Key Insight

By correlating income data with property values, we identified several emerging "wealth corridors" that were previously undocumented in standard census reports.

## Technical Breakdown

The map is built using **Maplibre GL JS** for vector tile rendering, with a custom **React** wrapper to manage state. Data processing was handled via Python scripts, outputting optimized GeoJSON tiles.
