## Overview

A comprehensive dashboard tracking global temperature anomalies over the last century. It aggregates data from multiple meteorological organizations into a single, cohesive interface.

## Key Insight

The rate of temperature increase has accelerated significantly in the last two decades, particularly in the northern hemisphere.

## Technical Breakdown

Built on **Next.js**, the application utilizes Server Components to fetch and process large datasets efficiently. The UI is styled with **Tailwind CSS**, and charts are rendered using **Recharts** for responsive, interactive data visualization.
